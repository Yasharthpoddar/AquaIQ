Authoritative scientific results, negative findings, manifests, test receipts, academic deliverables and production/research assets remain in place. The [archive inventory](repository_simplification_20261027/archives.json) records exact paths, original/Git SHA-256 values and checkout newline representation for 380 pruned tracked files.

The source commit is `6660e24d356cfc5794b9fb0bffad0bc050ade217`. It remains in the branch ancestry. Archived files comprise old captured pytest payloads and redundant accuracy drafts/plots/progress. Current tests generate their own fixtures and do not load these captures. Five captured files with an unverified Git-to-working-byte representation remain untouched for review.

## Recover without overwriting current files

From the repository root, materialize the complete archived set into a **new** scratch directory:

```powershell
.\venv\Scripts\python.exe -B scripts/restore_report_archive.py --destination scratch/NEW_REPORT_ARCHIVE_RESTORE
```

For a historical command requiring the original missing fixture paths, restore only that prefix in place:

```powershell
.\venv\Scripts\python.exe -B scripts/restore_report_archive.py --prefix reports/end_to_end_verification_20261022/checks_20261023/pytest_tmp --in-place
```

The helper verifies all Git objects and recovered bytes before writing. It refuses traversal, reparse targets, existing files and unknown representations; it never overwrites current evidence. Regenerated historical payloads are ignored to avoid accidentally recommitting them. Source-side reproduction commands still use fresh output paths.

Historical evidence manifests and previous cleanup snapshots describe a dated checkout. They were not rewritten to pretend the files were absent then. Restore the archived payloads and the corresponding historical source/assets before running those whole-tree preservation checks; their captured temporary files are not current production or scientific inputs.

The 12 ignored pytest trees removed in this pass were local generated test payloads mentioned only by old file inventories/preservation snapshots. Their source tests and actual result receipts remain. They are regenerated by the documented test commands, not recovered from Git. Raw observations, accepted datasets, model/rollback bundles and current tests were excluded from that pruning.
